# QML vs CML Research Project

A research-oriented pipeline comparing Classical Machine Learning (CML) and Quantum Machine Learning (QML) across datasets of varying complexity, culminating in biomedical and genomic applications.

## Project Structure
* `data/`: Contains raw and processed datasets (ignored by Git).
* `notebooks/`: Jupyter notebooks for exploratory data analysis and cloud execution.
* `src/`: Core Python modules for preprocessing, classical models, quantum models, and evaluation.
* `configs/`: YAML configuration files for reproducible experiments.
* `experiments/`: Execution scripts for running the pipeline.
* `results/`: Output JSON/CSV metrics and visualization plots.

## Installation

pip install -r requirements.txt
